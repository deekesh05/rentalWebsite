# 🚗 Vehicle Rental Website

## 📌 Overview
This project is a full-stack Vehicle Rental Web Application developed using PHP and MySQL. It allows users to browse available vehicles, make bookings, and manage reservations efficiently through an intuitive interface.

## 🚀 Key Features
- User Authentication (Login & Registration)
- Browse and Search Vehicles
- Online Booking System
- Admin Dashboard for Management
- Booking History Tracking

## 🛠️ Tech Stack
- Frontend: HTML, CSS, Bootstrap
- Backend: PHP
- Database: MySQL

## ⚙️ Setup Instructions
1. Install and start XAMPP (Apache & MySQL)
2. Clone the repository:
   ```bash
   git clone https://github.com/deekesh05/rentalWebsite.git
3. Import the provided. sql file into phpMyAdmin
4. Place the project folder inside htdocs

5. Run the application in your browser:
http://localhost/rentalWebsite
